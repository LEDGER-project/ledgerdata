# ledgerdata: The LEDGER Python Client

This Repo contains the LEDGER Python Client

## Installation

```bash
uv add git+https://github.com/LEDGER-project/ledgerdata.git@main 
```

or with pip

```bash
pip install git+https://github.com/LEDGER-project/ledgerdata.git@main
```

## Documentation

The official documentation for the entire LEDGER project is available at: [https://ledger-project.github.io/](https://ledger-project.github.io/)
